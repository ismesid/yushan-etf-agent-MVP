# 三因子分析：選擇理由、數值解讀與執行方式

文件版本：1.19｜更新：2026-10-11｜對應設計：[design1001.md §3、§7.1、§8](../design1001.md)

本頁說明目前已實作的歷史原價分析。專案架構與快速入口見 [README](../README.md)，欄位與模組責任見 [資料合約](data_contracts.md#原價歷史三因子分析)。

## 為什麼先用這三個指標

設計第一版的主題是「價格動能與風險控制」：先觀察近期表現、目前價格位置及每日漲跌幅度，再討論選股與配置。現有官方月行情已提供所需收盤價，三個公式容易重算、對回來源，也不必先接入財報、法人或新聞資料，適合在 MVP 階段建立可檢查的分析流程。

20 個交易日約為一個月，正好與目前先完成 2025-09 的資料範圍配合。20 段相鄰日報酬需要 21 筆價格；均線則使用其中最後 20 筆。20 日與年化 252 日均為專案分析約定，並非官方指定參數，也沒有經回測證明為最佳值。

動能與均線偏離都是價格趨勢訊號，彼此可能相關。這三欄主要涵蓋**趨勢與波動兩個面向**，不是三種獨立的投資優勢，也尚未包含企業獲利、估值、法人買賣或產業分散。先把這份基礎分析做好，後續才有一致的數值可供比較、加入新資料及檢驗策略。

## 每個數值代表什麼

對同一股票依交易日排列 21 筆收盤價，記為 `P0...P20`；`P0` 最早、`P20` 最後。日簡單報酬為 `ri = Pi / P(i-1) - 1`，共有 20 個。

| 指標／CSV 欄位 | 公式 | 回答的問題 | 怎麼解讀 |
|---|---|---|---|
| 20 日動能 `mom20_pct` | `P20 / P0 - 1` | 這段期間價格累積漲跌多少？ | 正值表示末價高於首價；負值表示下跌。例如首價 100、末價 110，動能為 10%。只看兩個端點，無法知道中間是否劇烈起伏。 |
| 均線偏離 `trend20_pct` | `P20 / mean(P1...P20) - 1` | 最後價格相對近期平均位在哪裡？ | 正值表示高於最後 20 筆的簡單移動平均（SMA20）；負值表示低於均線。例如末價 110、平均 105，偏離約 4.76%。偏離較高可能反映近期強勢，也可能過熱、面臨回撤，不能直接視為越高越好。 |
| 年化波動 `vol20_annual_pct` | `sample_stdev(r1...r20) × sqrt(252)` | 每天的漲跌幅度有多不穩定？ | 使用樣本標準差，分母為 19（`ddof=1`）。數值高表示近期日報酬起伏較大；低表示較平穩。它不是年報酬率、虧損機率或最大損失；較低波動也不代表穩賺。 |

動能與均線偏離的差別在於**整段首尾變化**與**最後價格的位置**：兩檔股票首末價格相同，中間走勢不同，就可能有相同動能、不同均線偏離。波動則補充這段路徑的每日起伏，不能只靠首末價格計算。

乘上 `sqrt(252)` 是把近期日波動換成慣用的年化尺度，便於使用同一尺度比較；它不是用一個月資料預測未來全年漲跌或損失。這份表採未調整原價，除權息等公司行動也可能造成價格跳動，影響三個指標。

### 目前的真實歷史例子

截至 2025-09-30，台積電（2330）的視窗首末收盤為 1165／1305 千元新臺幣／張。動能為 `1305 / 1165 - 1`；最後 20 筆平均與 20 個日報酬分別用來計算另兩項。

| 股票 | 20 日動能 | 均線偏離 | 年化波動 |
|---|---:|---:|---:|
| 2330 台積電 | 12.017167% | 4.337398% | 23.192445% |
| 5274 信驊 | 0.697906% | 0.934393% | 37.658959% |

2330 的數值表示這段期間原價上漲約 12.02%、末價高於近期平均約 4.34%，近期日報酬起伏換成年化尺度約 23.19%。這不是下一個月的預測或已確認的投資報酬。

## 權重查詢紀錄：供開會討論

查詢整理日期：2026-10-11。**40% 動能／25% 均線偏離／35% 低波動來自本專案設計草案，不是下列文獻的結論。** 目前沒有找到使用同樣三個指標定義、同樣 20 日期間與此精確配比的公開標準方法，因此不能稱它為業界常用配方或最佳權重。使用者已同意先沿用這個配比完成 MVP 排名；它仍是待檢驗的初始設定。

公開資料支持研究動能、趨勢與低波動，但它們的期間、計算、合成方式與我們不同：

| 參考來源與位置 | 公開方法的做法 | 能支持什麼、與本專案的差別 |
|---|---|---|
| [MSCI Momentum Indexes Methodology，2025-04 版，第 4 頁](https://www.msci.com/indexes/documents/methodology/2_MSCI_Momentum_Indexes_Methodology_20250417.pdf#page=4) | 6 個月與 12 個月動能，排除最近一個月；經波動調整、標準化後，兩個動能分數各占 50%。 | 動能可有明確、可重算的指數方法；不是本專案含最近月份的 20 日動能，也沒有均線偏離占 25% 的設定。此連結是指定的 2025 年版本，MSCI 另有 2026 年更新，並非宣稱最新方法。 |
| [S&P QVML Multi-Factor Indices Methodology，2024-08 公開版，第 6 頁](https://www.spglobal.com/spdji/en/documents/methodologies/methodology-sp-qvml-multi-factor-indices.pdf#page=6) | 品質、價值、動能、低波動四種標準化分數取平均，各占 25%。 | 可作等權合成的公開實例；因子組合與本專案不同，不能推出三因子應用 40／25／35。這是供查核的公開版本，網址內容日後可能更新。 |
| [S&P Low Volatility Indices Methodology，Americas 章節](https://www.spglobal.com/spdji/en/documents/methodologies/methodology-sp-low-volatility-indices.pdf) | 用過去 252 個交易日的波動選股，股票配置權重與波動成反比。 | 低波動可用於選股及股票配置；這裡的配置權重與本專案因子分數占 35% 是不同層次。波動觀察期也不是本專案的 20 日。 |
| [Kenneth French Data Library：每日動能因子定義，Construction／Stocks 段](https://mba.tuck.dartmouth.edu/pages/Faculty/ken.french/Data_Library/det_mom_factor_daily.html) | 使用 prior (2–12) 報酬，跳過最近約一個月。 | 經典研究常用中期動能；不能直接把研究結果套用到含最近月份的 20 日短期動能或我們的權重。 |
| [Valeriy Zakamulin：均線交易研究的作者書籍資料頁](https://vzakamulin.weebly.com/book-1.html) | 列出均線、市場擇時、動能及價格與均線差值的研究章節。 | 可供追查均線與趨勢研究；作者資料頁本身不能證明本專案 `trend20` 應占 25%，也未提供這 146 檔的實際相關係數。 |

開會時優先討論：

1. 動能與均線偏離都由近期價格推導，可能重複反映趨勢。40%＋25% 是公式中兩項係數合計 65%，不能直接解讀成已量測的趨勢曝險；目前尚未計算這 146 檔的實際相關性。
2. 是否保留這個配比作基準，後續比較三因子等權及其他設定？應以更多歷史期間、交易成本與樣本外表現檢驗，不能用目前單一月份證明哪組權重較好。
3. 正式比較前，何時補調整價／公司行動、歷史可知時間與可交易股票池？目前原價、20 日與年化 252 日都是分析約定，與上述公開方法不能直接視為同一策略。

本批只記錄研究並依已同意的 40／25／35 執行排名；相關性分析、增加期間、等權比較及回測另列後續工作。

## 後續怎麼運用

目前保存原始因子，並以同一截止日的 146 檔完整分析股票計算相對排名及綜合分數：動能、均線偏離得分方向向上，波動轉為低波動得分。各因子得分與加權貢獻都保存，配比集中於 [排名設定](../config/ranking.json)。公式、解讀、輸出與操作見 [排名說明](ranking.md)。

排名提供可檢查的候選比較。之後仍需正式資格與流動性篩選，將候選數值、來源、市場背景及既有持股交給決策模型，再由程式處理配置、風控、股數、現金和帳務。三個指標及綜合分數本身不等於買賣指令；排名、配置與模型是不同模組，詳見 [專案架構](../README.md)。

## 先看哪個檔案

先在本頁理解指標與解讀方式，再查看每次執行的 CSV／JSON。每次另建 `data/cache/features/<資料截止日>/<執行版本>/`，不覆寫先前分析，也不再產生重複的 Markdown 說明。

| 檔案 | 用途 | 本機已完成的 2025-09-30 版本 |
|---|---|---|
| `features.csv` | 用 Excel 查看、篩選每股三因子原始值；一股一列 | 146 檔分析表（本機路徑 `data/cache/features/2025-09-30/20261011T160349_3b42fa16/features.csv`） |
| `metadata.json` | 查共同日期、公式、單位、內部數值、來源版本與排除紀錄 | 計算來源（本機路徑 `data/cache/features/2025-09-30/20261011T160349_3b42fa16/metadata.json`） |

這些產物是本機快取，Git 忽略 `data/cache`；新 checkout 不會自帶上述執行版本，需先取得月行情、日曆與視窗，再重算分析。

CSV 共六欄：`ticker`、`name`、`market`、`mom20_pct`、`trend20_pct`、`vol20_annual_pct`。三因子欄位都是**百分數**，`10.000000` 表示 10%，不是 1000%；不要直接當成內部小數比率。CSV 使用 UTF-8 BOM，百分數顯示六位小數、`ROUND_HALF_UP` 取捨。

JSON `rows[].values` 以十進位字串保存比率，例如 `0.10` 表示 10%；計算用 34 位 Decimal、`ROUND_HALF_EVEN`，避免依 CSV 的六位顯示值再算。每股另保留 21 筆價格／20 個報酬及 `source_metadata`；共同日期、公式、原價標記與輸入雜湊集中保存。完整欄位責任見 [資料合約](data_contracts.md#原價歷史三因子分析)。

本版特徵版本為 `price-features-v1-c9e2191b62ec`，分析母體為 150 檔中已有完整視窗的 146 檔；3718／7750／7769／7828 沿用原報告的不足紀錄，未補零、未重新查核。後續缺失處理留在 [checklist DATA-22](../checklist.md)。

## 執行與重算

在專案根目錄用 PowerShell 執行，使用已保存的視窗報告，全程離線：

```powershell
$env:PYTHONPATH = (Resolve-Path -LiteralPath 'src').Path
python -B -m etf_agent.cli history-features --window-report data/cache/history_windows/2025-09-30/20261011T154440_9842e79e/window_report.json --output data/cache/features
```

`--window-report` 指向前一步的視窗 JSON；`--output` 是分析保存根目錄，省略時預設 `data/cache/features`。本版只分析報告內 `window_complete=true` 的股票，依共同日期讀日表收盤 `close_raw_ktwd_per_lot`，不疊加月表、不讀截止日之後。`as_of` 是歷史資料截止日，不是該日盤前決策時間。

成功時 CLI 顯示本次 CSV、JSON 路徑與本頁說明位置，並回傳 exit 0。相同輸入重算會得到相同數值與 `feature_version`，但使用新的執行目錄、時間及 run ID。可替換成另一份已完成視窗 JSON；目前輸入仍須符合 21 筆、同月份的既有視窗範圍。

若輸入格式不符、原 manifest 或日表與先前視窗驗收雜湊不同，會報錯並回傳 exit 2，停止計算。應先核對輸入版本與路徑，再使用對應資料重新建立視窗；不要修改報告雜湊繞過檢查。這是防止沿用已變更資料，未重新掃描所有原始快取。

## 程式邊界與資料限制

[features.py](../src/etf_agent/sub_agents/data_agent/features.py) 的 `calculate_price_features()` 為純計算函式；`analyze_history_features()` 讀日表、核對既有輸入並整理來源；`write_feature_analysis()` 保存 CSV／JSON。CLI 在 [cli.py](../src/etf_agent/cli.py) 組合這些步驟，沒有模型呼叫、網路請求或帳戶修改。

目前使用未調整原價；公司行動、歷史公開時間 `known_at`、臨時休市與正式可交易資格尚未完整核實。原行情的 `return_close` 留空、`adjustment_status=unresolved` 及 `tradable=false` 不因計算而改變，分析產物 `submission_ready=false`。這份分析也尚未串接正式 `MarketSnapshot`／`FeatureTable` 或完整 source→observation 證據鏈。

既有三項重點測試已驗可手算／固定價格、完整視窗與來源／重算一致、資料被改後阻擋；本頁文件整理不新增測試。必要時可重跑 `python -B -m unittest discover -s tests -p test_features.py -v`，不需因單純閱讀文件而重跑全套。
